# Campus Academic Companion 🎓

A responsive, client-side web application designed to help university students manage attendance targets, track class schedules, and organize daily academic routines.

---

## 📌 Problem Statement
College students often struggle to keep track of their attendance percentages across various subjects and balance them against mandatory institutional cutoffs. Campus Academic Companion provides an intuitive dashboard to calculate required attendance, manage daily lectures, and keep track of coursework in one place.

---

## 🚀 Features
- **Attendance Tracker & Calculator:** Calculate current attendance percentages and determine how many classes can be missed or need to be attended to stay above threshold targets.
- **Schedule & Subject Organizer:** Manage course timetables, lecture timings, and subject lists.
- **Clean Responsive UI:** Lightweight, interactive interface built with vanilla web technologies for zero setup.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structure and layout.
- **CSS3:** Custom styles, responsive grid/flexbox layouts.
- **JavaScript (ES6):** Dynamic attendance calculation and client-side state handling.
